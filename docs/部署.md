# 部署说明

产物是**一个 `dist/index.html`**（约 20.7 MB，CSS/JS/资源全部内联），任何静态托管都能跑。下面给 Cloudflare Pages 的两条路径。

## 一、Cloudflare Pages 控制台（推荐，第一次用这个）

仓库推到 GitHub 后，在 Cloudflare Dashboard → **Workers & Pages → Create → Pages → Connect to Git**：

| 配置项 | 值 |
| --- | --- |
| Framework preset | **None**（不要选 Vite/Next，本项目不是框架工程） |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | `/`（留空即仓库根） |
| 环境变量 | `NODE_VERSION = 22`（已带 `.nvmrc`，一般会自动识别） |

> 构建是纯 Node 字符串拼接，**零依赖**，`npm install` 只会生成一个空 lock，几十秒内出结果。不需要 `npm run build` 之外的任何步骤。

## 二、GitHub Actions + wrangler（推荐，长期用这个）

`.github/workflows/deploy-cloudflare-pages.yml` 已就绪：push 到 `main` → 构建 → `upload-artifact` → `wrangler pages deploy`。

首次需要在仓库 **Settings → Secrets and variables → Actions** 里加两个 secret：

| Secret | 取值位置 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | CF Dashboard → My Profile → API Tokens → Create Token → 模板「Edit Cloudflare Workers」，权限需含 **Cloudflare Pages: Edit** |
| `CLOUDFLARE_ACCOUNT_ID` | CF Dashboard → Workers & Pages 右侧栏 Account ID |

同时把 `wrangler.toml` 里的 `name` 改成你的 Pages 项目名（默认 `starteditor`），或在 workflow 里改 `--project-name=`。

项目不存在时先建一次：

```bash
npx wrangler pages project create starteditor --production-branch main
```

## 三、本地手动发布

```bash
npm run check          # 自检（构建 + 结构 + 可达性 + 体积）
npx wrangler pages deploy dist --project-name=starteditor
```

## 四、其他平台

| 平台 | 构建命令 | 产物目录 | 备注 |
| --- | --- | --- | --- |
| Vercel | `npm run build` | `dist` | 已带 `vercel.json` |
| Netlify | `npm run build` | `dist` | 可加 `netlify.toml`，或直接拖 `dist/` |
| GitHub Pages | `npm run build` | `dist` | 用 `actions/deploy-pages`，单文件无路径问题 |
| 自有服务器 / OSS / COS | — | `dist/` | 直接把 `index.html` 传上去，配 `text/html` 即可 |

## 五、上线后要确认的三件事

1. **首屏**：加载动画应正常出现并淡出（`B02/B03/B06` 三层都生效才说明 DEFLATE 解码链路没断）。
2. **控制台**：不应出现 `bl-inflate: invalid huffman code` 之类报错 —— 出现即代表某个资源块被格式化/截断了。
3. **体积与缓存**：`index.html` 建议 `max-age=0, must-revalidate`（`public/_headers` 已配好），因为整站都在这个文件里，长缓存会导致改版不生效。

## 排障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 白屏、只停在加载动画 | `bl-embedded-bundle` / `__RES__` 被改动 | `npm run verify` 对基线指纹，或回滚该块 |
| `missing include` | 模板引用了不存在的文件 | 按报错路径补齐，或修 `src/index.html` 的占位 |
| 构建通过但线上 404 | 产物目录填错（填成 `src` 或 `public`） | 改回 `dist` |
| 上传被拒（>25 MiB） | 单文件超过 Pages 上限 | 当前 20.7 MB 安全；若后续激增需拆分资源层 |
